About ScopeKeeper

ScopeKeeper helps freelancers check requests against dated project evidence and prepare editable replies.

Technology

  • Python serves the app and evaluates requests against approved evidence.
  • HTML, CSS and vanilla JavaScript provide the review interface.
  • Hindsight stores and retrieves project history. A self-hosted Hindsight instance can run in Docker.

Demo data

The demo uses fictional agreements and amendments. In simulation mode, the app uses fictional memory fixtures. Only a confirmed client-approved amendment changes the demo agreement.
